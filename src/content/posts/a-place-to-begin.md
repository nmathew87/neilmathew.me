This is a sample post to try out the blog. It can be edited or replaced with the first real article.

## Start with a question

A useful post doesn’t have to begin with an answer. It can start with something that caught your attention, a problem you’re working through, or a small discovery worth keeping.

This space has room for short notes as well as longer explorations. Some ideas need a few paragraphs. Others need a diagram, a piece of code, or an experiment you can interact with.

## Make something small

The quickest way to understand an idea is often to build a small version of it. Keep the scope narrow enough to see what’s happening, then change one thing at a time.

```js
function startWithAnIdea(idea) {
  return {
    question: idea,
    nextStep: 'Make something small.',
  };
}
```

Code examples have syntax highlighting in both light and dark mode. Ordinary paragraphs, **bold text**, *emphasis*, and [links](https://developer.mozilla.org/) work too.

> A notebook can hold unfinished thoughts. The useful part is returning to them.

## Leave room to explore

A post might capture a lesson, document a decision, or leave a question open. The format can follow the idea.

- Write down the question.
- Try the smallest useful experiment.
- Notice what changed.
- Share what you learned.

For now, this is one page and a place to begin.
